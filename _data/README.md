# 学习路径配置文件使用指南

## 文件说明

`learning_paths.yml` 用于定义分类页面中文章的学习顺序和主题分组。

## 配置格式

```yaml
分类名称:
  主题名称:
    - "文章标题1"
    - "文章标题2"
    - "文章标题3"
  
  另一个主题:
    - "文章标题4"
    - "文章标题5"

另一个分类:
  主题A:
    - "文章标题6"
```

## 重要注意事项

### 1. 标题必须精确匹配
配置文件中的标题必须与文章 Front Matter 中的 `title` **完全一致**：

```yaml
# ✅ 正确
- "什么是深拷贝和浅拷贝？"

# ❌ 错误（缺少问号）
- "什么是深拷贝和浅拷贝"

# ❌ 错误（标点符号不一致）
- "什么是深拷贝和浅拷贝？"  # 全角问号

# ❌ 错误（空格不一致）
- "什么是深拷贝和浅拷贝 ？"  # 多余空格
```

### 2. 分类名称必须匹配
分类名称必须与文章 Front Matter 中的 `categories` 一致：

```markdown
---
categories: [Java基础]  # ← 这里的名称
---
```

```yaml
Java基础:  # ← 必须与上面完全一致
  基础语法与面向对象:
    - ...
```

### 3. 学习顺序
- 主题按照 YAML 中的顺序展示
- 文章按照列表中的顺序展示
- 建议按照"由浅入深"的原则排列

## 如何添加新文章

### 步骤1: 确认文章标题
查看文章的 Front Matter：
```markdown
---
title: "新文章的标题"
categories: [Java基础]
---
```

### 步骤2: 添加到配置文件
在对应分类和主题下添加：
```yaml
Java基础:
  基础语法与面向对象:
    - "已有文章1"
    - "已有文章2"
    - "新文章的标题"  # ← 添加在这里
```

### 步骤3: 确定位置
- 如果是基础内容，放在主题开头
- 如果是进阶内容，放在主题末尾
- 如果需要前置知识，放在前置文章之后

## 如何添加新主题

在分类下添加新的主题分组：

```yaml
Java基础:
  基础语法与面向对象:
    - ...
  
  新的主题名称:  # ← 添加新主题
    - "主题下的文章1"
    - "主题下的文章2"
```

## 如何添加新分类

在文件末尾添加新分类：

```yaml
设计模式:
  常用设计模式:
    - ...

新分类名称:  # ← 添加新分类
  主题A:
    - "文章1"
  主题B:
    - "文章2"
```

## 降级机制

如果某个分类没有在此配置文件中定义，`categories.html` 将自动使用原有的排序方式（按日期或字母顺序），确保网站功能不受影响。

## 常见错误

### 错误1: 文章不显示
**原因**: 标题不匹配  
**解决**: 复制粘贴文章 Front Matter 中的 title，确保完全一致

### 错误2: YAML 解析错误
**原因**: 缩进或格式错误  
**解决**: 
- 使用空格缩进，不要用Tab
- 每级缩进使用2个空格
- 列表项使用 `- "内容"`

### 错误3: 顺序不对
**原因**: YAML 对象的顺序在某些解析器中不保证  
**解决**: 使用列表格式确保顺序

## 最佳实践

### 1. 主题命名
- 使用清晰、描述性的主题名称
- 避免过长的主题名称（建议10字以内）
- 中文主题名使用全角标点

### 2. 文章排序
- 遵循"先易后难"原则
- 概念性文章在前，应用性文章在后
- 有依赖关系的文章按依赖顺序排列

### 3. 维护建议
- 定期检查是否有遗漏的文章
- 新增文章时及时更新配置
- 定期审查学习路径是否合理
