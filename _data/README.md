# 数据文件说明

本目录包含网站使用的数据文件。

## 文件列表

### home_order.yml

**自动生成的首页文章排序数据**

- **生成方式**: 由 `scripts/generate_home_data.py` 自动生成
- **数据来源**: `学习路径排序_优化版.md`
- **用途**: 定义首页文章的显示顺序和分类结构
- **注意**: 请勿手动编辑此文件

#### 数据结构

```yaml
sections:
  - name: "分类名称"
    range: "1-33"
    subsections: []
    questions:
      - order: 1
        title: "题目标题"
      - order: 2
        title: "题目标题"

title_to_order:
  "题目标题": 1
  "题目标题": 2

title_to_category:
  "题目标题": "分类名称"
  "题目标题": "分类名称"
```

## 如何更新数据

### 修改学习路径排序

1. 编辑 `学习路径排序_优化版.md` 文件
2. 运行生成脚本：
   ```bash
   python scripts/generate_home_data.py
   ```
3. 数据文件 `home_order.yml` 将自动更新

### 添加新文章

1. 在 `_posts/` 目录创建新文章
2. 在 `学习路径排序_优化版.md` 中添加题目标题
3. 运行生成脚本更新数据

### 注意事项

- 文章标题必须与 `_posts/` 中的 Front Matter `title` 字段完全一致
- 包括标点符号、空格等必须精确匹配
- 分类名称需要与文章的 `categories` 字段对应

## 故障排查

### 文章不显示

**可能原因**：
- 标题不匹配：检查 `学习路径排序_优化版.md` 中的标题是否与文章 Front Matter 完全一致
- 文章未发布：检查文章日期是否在未来

**解决方法**：
1. 比对文章标题，确保完全一致
2. 重新运行生成脚本
3. 清除 Jekyll 缓存：`bundle exec jekyll clean`

### 排序错误

**可能原因**：
- `学习路径排序_优化版.md` 中的序号不连续
- 数据文件未更新

**解决方法**：
1. 检查 `学习路径排序_优化版.md` 格式
2. 重新运行生成脚本
3. 检查生成脚本输出的统计信息
