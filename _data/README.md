# 数据文件说明

本目录包含网站使用的数据文件。

## 文件列表

### home_order.yml

**自动生成的首页文章排序数据**

- **生成方式**: 由 `scripts/generate_home_data.py` 自动生成
- **数据来源**: `学习路径排序_优化版.md`
- **用途**: 定义首页文章的显示顺序和分类结构
- **注意**: 请勿手动编辑此文件

#### 数据结构

```yaml
sections:
  - name: "分类名称"
    range: "1-33"
    subsections: []
    questions:
      - order: 1
        title: "题目标题"
      - order: 2
        title: "题目标题"

title_to_order:
  "题目标题": 1
  "题目标题": 2

title_to_category:
  "题目标题": "分类名称"
  "题目标题": "分类名称"
```

### 学习路径排序_优化版.md

**学习路径主文件**

- **用途**: 定义所有题目的分类和顺序
- **结构**: 大分类 → 小分类 → 题目列表
- **学习路径逻辑**: Java基础 → JVM/并发 → MySQL/Redis → Spring → 分布式架构

### 第一步：准备新题目清单

1. 创建新题目文件（如 `new_title.txt`），每行一道题目
2. 确保每道题目都有对应的文章文件在 `_posts/` 目录中
3. 文章的 `title` 字段必须与题目清单中的标题**完全一致**

## 常见问题

### Q1: 如何确定新题目的插入位置？

**A**: 遵循以下原则：
1. 查看题目考察的知识点
2. 找到对应的大分类
3. 在大分类中找到最匹配的子分类
4. 在子分类中找到难度相近的位置插入

**示例**：
- "为什么 HashMap 会产生死循环？" → 集合框架 → HashMap相关题目之后
- "JVM 为什么使用元空间替换永久代？" → JVM → 内存结构子分类

### Q2: 新增分类应该放在什么位置？

**A**: 根据知识体系的递进关系：
- **基础组件**（如 Netty）→ 放在框架之后、分布式之前
- **中间件**（如 ZooKeeper）→ 放在分布式相关章节
- **综合实战**（如架构设计）→ 放在最后

**不要**简单地追加到末尾，要考虑学习路径的合理性。

### Q3: 题目序号重排有什么技巧？

**A**: 推荐方法：
1. 使用编辑器的"查找替换"功能
2. 分段重编号（如每个大分类单独处理）
3. 重编号后使用脚本验证连续性

**注意**：
- 子分类范围要与实际题目序号一致
- 大分类范围要覆盖所有子分类

### Q4: 脚本生成失败怎么办？

**A**: 检查以下几点：
1. `学习路径排序_优化版.md` 格式是否正确
2. 题目序号是否连续
3. 分类标题格式是否符合脚本规则：
   - 大分类：`## 一、Java基础（1-79）`
   - 子分类：`### 1.1 面向对象基础（1-11）`
   - 题目：`1. 题目标题`

### Q5: 如何验证题目是否正确集成？

**A**: 三步验证法：
1. **视觉检查**：浏览 `学习路径排序_优化版.md`，确认题目顺序合理
2. **脚本验证**：运行生成脚本，检查输出的统计信息
3. **文件验证**：打开 `home_order.yml`，搜索新增题目标题
